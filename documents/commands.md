# Commands

`/ex` — opens the interface

`/ex jumpto <x> <y>`
`/ex jumpto <anchor-name>`

`/ex current-position`

`/ex mode [anchored|free]`

`/ex up [amount]`
`/ex down [amount]`
`/ex left [amount]`
`/ex right [amount]`

`/ex cycle`

`/ex profiles switch <name>`
`/ex profiles set-default <name>`
`/ex profiles subscribe <name>`
`/ex profiles invite <profile-name> <player-name> <read-only|full>`
`/ex profiles settings <name> <turn-private|turn-public-read|turn-public-write>`

`/ex buffer load [name]`

`/ex anchor add <name> <x> <y>`
`/ex anchor delete <name>`
`/ex anchor rename <old-name> <new-name>`
`/ex anchor info <name>`
